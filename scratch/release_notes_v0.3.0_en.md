# ⚡ Sparky AI v0.3.0 — Next-Gen Agentic Intelligence & Smart Memory Release

Sparky AI v0.3.0 brings a major leap in desktop AI capabilities, featuring episodic project memory, 30 domain-specific agent presets, 23 glowing accent themes, 12 custom geometric orb skins, intelligent folder-grouped model pickers, and native slash commands!

---

## 🌟 What's New in v0.3.0

### 🎨 1. 23 Glowing Color Themes & 12 Geometric Orb Shapes (Collapsible Accordion UI)
- **23 Aesthetic Theme Palettes:**
  - *Classic Lights:* Sunset, Cyberpunk, Emerald, Amethyst, Solar, Cosmic, Ocean, Midnight.
  - *15 New Vibrant Themes:* Aurora (Northern Lights), Matrix (Terminal Green), Inferno (Magma Flame), Glacier (Arctic Ice), Synthwave (80s Neon Pink), Tokyo Night (Neon Sakura), Nebula (Violet Galaxy), Amber (Warm Honey), Coral (Living Reef), Crimson (Royal Ruby), Vaporwave (Pastel Cyan), Forest (Deep Pine), Obsidian (Stealth Titanium), Lavender (French Lilac), Dracula (Gothic Orchid).
- **12 Unique Orb Geometries:**
  - Sphere (Circle), Smooth Square (Squircle), Cyber Hexagon, Crystal Diamond, Octagon, Delta Prism (Triangle), Aegis Shield, Cosmic Star, Capsule (Pill), Organic Leaf, Rhombus, and Techno Cross.
- **Collapsible Accordions:** Both the Accent Skin and Orb Geometry selectors in Settings feature smooth expand/collapse accordions with item counter badges and SVG chevrons.

### 🧠 2. Episodic Project Memory & Autonomous Compaction
- **Persistent Context Per Project:** Full project isolation with episodic memory and dialogue history (`projectMemory.js`).
- **Autonomous LLM Compaction:** Automatic background summarization triggers when context reaches the threshold (default 75%, configurable between 30%–95%).
- **Live Memory Meter:** Real-time token capacity gauge next to the prompt input.

### 🤖 3. 30 Categorized Agent Presets & Domain Workflows
- **6 Structured Domains:** `⚡ Core`, `💻 Engineering`, `🎨 Creative`, `📈 Strategy`, `🎓 Learning`, and `🛠️ Productivity`.
- **Specialized Workflows:** Software Architect, Debug Detective, SQL Guru, DevOps SRE, Security Auditor, UI/UX Designer, Direct-Response Copywriter, Worldbuilder, Branding Expert, Data Scientist, Product Manager (PRD/RICE), Growth Strategist, Financial Analyst, Socratic Mentor, Academic Researcher, Language Coach, Feynman Speed Learner, Meeting Facilitator, Legal Contract Analyst, and Time/Habit Coach.

### 📁 4. Smart Grouped & Searchable Quick Model Picker
- **Intelligent Prefix Folders:** Models automatically organize into brand and provider folders (`NVIDIA`, `OPENAI`, `ANTHROPIC`, `GOOGLE`, `OLLAMA`, etc.).
- **Collapsible Folders:** Starts neatly collapsed, with instant expansion upon click or search.
- **Live Search & Custom Models:** Instant filtering with auto-completion and direct `Enter` to specify custom models.
- **Max-Height Bounds & Provider Isolation:** Smooth in-popover scrolling without overflowing the screen.

### ⚡ 5. Native Slash Commands Engine
- `/compact`: Instantly compacts and summarizes active project episodic memory.
- `/clear`: Clears memory history for a fresh start.
- `/model <name>`: Switches model or lists available models.
- `/provider <name>`: Switches active AI provider.
- `/mode <name>`: Switches active operational mode.
- `/project <name>`: Switches active project workspace.
- `/help`: Displays formatted interactive table of all available local commands.

### 🖼️ 6. Multimodal Vision Capability Adaptation
- **Real-Time Capability Detection:** Automatically detects multimodal support from model metadata and naming.
- **Graceful UI Fallback:** Disables image upload and drag-and-drop safely when using text-only models.
