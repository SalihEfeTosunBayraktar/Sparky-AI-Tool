# ⚡ Sparky AI v0.3.0 — Next-Gen Agentic Intelligence & Smart Memory Release

Sparky AI v0.3.0 brings a major leap in desktop AI capabilities, featuring episodic project memory, 30 domain-specific agent presets, custom geometric orb skins, intelligent folder-grouped model pickers, and native slash commands!

---

## 🌟 What's New in v0.3.0

### 🧠 1. Episodic Project Memory & Autonomous Compaction
- **Persistent Context Per Project:** Full project isolation with episodic memory and dialogue history (`projectMemory.js`).
- **Autonomous LLM Compaction:** Automatic background summarization triggers when context reaches the threshold (default 75%, configurable between 30%–95%).
- **Live Memory Meter:** Real-time token capacity gauge next to the prompt input.

### 🤖 2. 30 Categorized Agent Presets & Domain Workflows
- **6 Structured Domains:** `⚡ Core`, `💻 Engineering`, `🎨 Creative`, `📈 Strategy`, `🎓 Learning`, and `🛠️ Productivity`.
- **20+ New Specialized Agents:**
  - **Engineering:** Software Architect, Debug Detective, SQL & Database Guru, DevOps & SRE, Security Auditor.
  - **Creative:** UI/UX Design Mentor, Copywriter Pro, Worldbuilder, Branding & Positioning.
  - **Strategy:** Data Scientist & Quant, Product Manager (PRD/RICE), Business & Growth Strategist, Financial Analyst.
  - **Learning:** Socratic Mentor, Academic Researcher, Polyglot Language Coach, Feynman Speed Learner.
  - **Productivity:** Meeting & Decision Facilitator, Contract & Clause Analyst, Habit & Time Architect.

### 💎 3. Customizable Geometric Orb Shapes & Glowing Skins
- **6 Unique Geometries:** Sphere (Circle), Smooth Square (Squircle), Cyber Hexagon, Crystal Diamond, Octagon, and Delta Prism (Triangle).
- **Decoupled Styling:** Change the floating Orb geometry anytime while seamlessly preserving your active glowing accent skin and animations.
- **Sleek Appearance Picker:** Unified compact swatches in the Settings panel with instant live preview.

### 📁 4. Smart Grouped & Searchable Quick Model Picker
- **Intelligent Prefix Folders:** Models automatically organize into brand and provider folders (`NVIDIA`, `OPENAI`, `ANTHROPIC`, `GOOGLE`, `OLLAMA`, etc.).
- **Collapsible Folders:** Starts neatly collapsed, with instant expansion upon click or search.
- **Live Search & Custom Models:** Instant filtering with auto-completion and direct `Enter` to specify custom models.
- **Max-Height Bounds & Provider Isolation:** Smooth in-popover scrolling without overflowing the screen, plus isolated per-provider model memory.

### ⚡ 5. Native Slash Commands Engine
- `/compact`: Instantly compacts and summarizes active project episodic memory.
- `/clear`: Clears memory history for a fresh start.
- `/model <name>`: Switches model or lists available models.
- `/provider <name>`: Switches active AI provider.
- `/mode <name>`: Switches active operational mode.
- `/project <name>`: Switches active project workspace.
- `/help`: Displays formatted interactive table of all available local commands.

### 🖼️ 6. Multimodal Vision Capability Adaptation
- **Real-Time Capability Detection:** Automatically detects multimodal support from model metadata and naming.
- **Graceful UI Fallback:** Disables image upload and drag-and-drop safely when using text-only models.
